# M6 Agent 编排

## 目标

实现受控天气 Agent：先解析和校验问题，再通过天气工具取得结构化数据，最后生成有依据的建议。

## 子任务

- [x] 定义 `WeatherToolRequest`、`WeatherToolResult`、ForecastRange 与 `IWeatherTool` 契约。
- [x] 实现天气工具参数解析和校验：城市、日期、7 天范围、日期范围及查询类型。
- [x] 实现城市解析：优先使用可用 Location，否则通过 `IGeocodingService` 搜索；无结果追问，多结果采用设计约定并说明。
- [x] 实现 Agent 问题相关性判断；非天气问题返回 OutOfScope，不调用天气服务。
- [x] 实现缺少城市或日期时的 NeedClarification 回复，不猜测缺失信息。
- [x] 工具内部复用天气查询/缓存链路，保证 Agent 与天气页数据一致。
- [x] 实现 `AgentPromptBuilder`，仅组装回答所需城市、日期、每日数据和目标日 06:00–22:00 逐小时摘要。
- [x] 在系统提示中限制主题、要求引用结构化数据、禁止编造、中文输出且控制长度。
- [x] 实现 `AgentReplyMapper`，返回回答、城市、日期、意图、证据和缓存/降级说明。
- [x] 实现 `AgentService.AskAsync` 全流程、取消及工具/生成器失败转换。
- [x] 编写 Fake 测试：缺城市/日期、完整问题、工具失败、超范围日期、非天气问题、城市无结果、缓存降级、取消和演示模式。

## 完成验收

- [x] Agent 仅由天气工具取得天气数值，模型生成不负责天气事实。
- [x] 所有回复类型及失败路径均有测试覆盖。
