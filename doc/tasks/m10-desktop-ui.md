# M10 桌面展示（Avalonia）

## 目标

完成 Avalonia MVVM 主窗口、天气与城市交互、AI 面板和设置页，并为异步状态提供清晰反馈。

## 子任务

- [x] 实现 `ViewModelBase` 的可观察属性、日志注入、互斥异步操作和重复触发时取消旧请求。
- [x] 实现 `MainWindowViewModel`：当前城市、天气状态、网络/存储提示、刷新、设置入口和城市选择协调。
- [x] 实现 `WeatherViewModel`：当前天气、逐小时、7 日、更新时间、来源、Stale 标识、加载/空/错误/重试状态。
- [x] 实现 `CitySearchViewModel`：关键词、搜索状态、结果列表、选择城市、空结果与取消行为。
- [x] 实现 `CityListViewModel`：收藏/取消收藏、最近访问和城市切换。
- [x] 实现 `ChatViewModel`：会话消息、快捷问题、发送、追问和错误提示。
- [x] 实现 `SettingsViewModel`：AI 模式、Base URL、模型、API Key 输入/脱敏、温度单位、主题和保存/清除命令。
- [x] 构建主窗口左右布局：天气内容区与 AI 对话区并列，包含搜索、当前城市和刷新。
- [x] 构建天气视图：核心天气字段、逐小时和未来 7 天。
- [x] 构建 AI 面板：三个快捷问题、消息滚动和发送状态。
- [x] 构建设置窗口或页面，输入 Key 时不回显明文已保存值。
- [x] 实现浅色、深色、跟随系统主题和运行时更新；主题设置持久化。
- [x] 实现温度显示换算、城市时区格式化和天气代码图标/描述映射。
- [x] 为天气、搜索和聊天分别维护主要异步状态；天气取消回到先前有效状态。
- [x] 实现应用启动恢复最后城市；无可恢复城市时进入空闲搜索状态。
- [x] 编写不启动 Avalonia 应用的 ViewModel Fake 测试，覆盖设置保存/清除/脱敏。
- [x] 注册所有当前 ViewModel 并在应用启动时完成服务组装。

## 完成验收

- [x] 首屏能辨认当前城市、天气状态、数据来源和更新时间。
- [x] 长天气/AI 内容可滚动，加载/空/错误/缓存状态可区分。
- [x] 浅色与深色主题下文字和交互控件可读，窗口缩放时主要区域不互相遮挡。
