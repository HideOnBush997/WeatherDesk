# M5 城市管理（收藏与最近访问）

## 目标

持久化收藏、最近访问和最后选择城市，并保证离线恢复不依赖地理编码服务。

## 子任务

- [x] 定义城市存储所需持久化抽象和领域接口实现边界。
- [x] 实现收藏添加，按 LocationId 幂等；实现取消收藏，不存在时返回成功。
- [x] 实现最近访问 Upsert 和按 VisitedAtUtc 倒序读取。
- [x] 将最近访问上限集中为常量，超限时删除最早记录。
- [x] 保存完整 Location 快照，确保无网络时可从收藏/最近列表恢复城市。
- [x] 实现最后选择城市状态的读写及关联城市恢复；找不到时返回空状态。
- [x] 将存储异常映射为 Storage Result，保证取消令牌传播。
- [x] 编写测试：收藏/取消/重复操作、排序和上限、恢复 LastCity、收藏与最近访问独立、存储失败。

## 完成验收

- [x] 城市操作不依赖 UI、HTTP 或具体 EF 实体。
- [x] 用户重启后可恢复收藏、最近访问及最后选择城市。
