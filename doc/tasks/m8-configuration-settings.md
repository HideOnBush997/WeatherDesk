# M8 配置与设置存储

## 目标

保存用户偏好和 AI 配置，并保护 API Key 不进入普通设置文件、Git 或日志。

## 子任务

- [x] 实现 `AppPaths`，统一定义应用数据根目录、数据库、设置 JSON 和凭据文件路径。
- [x] 实现 `JsonSettingsStore` 的设置加载/保存，支持默认值和损坏配置回退。
- [x] 设置 JSON 仅包含 AI 模式、Base URL、模型、温度单位和主题，不包含 API Key。
- [x] 实现 `SecretProtector` 与凭据读写；Windows 采用 DPAPI 加密，解密失败按未配置 Key 安全处理。
- [x] 实现 API Key 获取、设置和清除；返回给 UI 的展示值使用脱敏工具。
- [x] 实现 `SecretMasker`，隐藏完整 Key，仅按约定显示脱敏值。
- [x] 目录创建失败时返回可观测存储失败，并支持调用方使用内存实现降级。
- [x] 确保取消令牌、文件异常和 JSON 异常均被映射为 Result，不泄露敏感内容。
- [x] 编写设置测试：保存加载一致、默认值、损坏文件回退、API Key 不写入 JSON、Key 加解密/失败处理和脱敏。
- [x] 将 `ISettingsStore` 注册到具体实现并提供安全的内存降级实现（如由组装层选择）。

## 完成验收

- [x] 仓库和普通日志中不出现明文 API Key。
- [x] 设置页可读取、保存、清除 Key 与偏好设置。
